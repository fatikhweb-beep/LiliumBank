Lilium Bank — بسته کامل مرورگری و PWA

محتویات:
- index.html: آخرین نسخه برنامه با اصلاح عنوان «قسط ۲»، «قسط ۳» و ...
- manifest.webmanifest: تنظیمات نصب برنامه
- sw.js: سرویس‌ورکر و پشتیبانی از پوسته آفلاین
- icon-192.png و icon-512.png: آیکون‌های نصب

انتشار روی GitHub Pages:
1) تمام فایل‌های داخل ZIP را مستقیماً در ریشه (Root) مخزن قرار بده؛ داخل پوشه جداگانه نگذار.
2) در GitHub وارد Settings > Pages شو.
3) گزینه Deploy from a branch، شاخه main و پوشه /(root) را انتخاب و ذخیره کن.
4) سایت را با آدرس HTTPS باز کن. برای نصب، از منوی مرورگر گزینه Install app یا Add to Home screen را بزن.

اجرای مستقیم:
فایل index.html را می‌توان با مرورگر باز کرد؛ اما قابلیت نصب PWA و سرویس‌ورکر فقط روی HTTPS یا localhost فعال می‌شود.

نکته مهم: اطلاعات برنامه در حافظه مرورگر همان دستگاه ذخیره می‌شود. قبل از جایگزینی نسخه قبلی، از اطلاعات مهم نسخه پشتیبان بگیر.
